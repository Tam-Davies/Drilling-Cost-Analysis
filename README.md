# 🛢️ Drilling Cost Predictor

A Streamlit web app that predicts drilling cost from well depth using a log-linear regression model trained on historical drilling data.

**Live demo:** https://drilling-cost-analysis.onrender.com
*(hosted on Render's free tier — first load may take 30–50s if the app has been idle)*

## Overview

Given a well depth, the app predicts drilling cost using:

```
ln(Cost) = intercept + slope × Depth
Cost     = exp(intercept) × exp(slope × Depth)
```

The model is a scikit-learn `LinearRegression` fit on `Depth → ln(Cost)`, trained/tested with an 80/20 split.

**Test set performance:**
- R²: 0.9996
- RMSE: 0.0015
- MAE: 0.0013

*(metrics computed on the ln(Cost) scale, matching how the model was trained)*

## Setup

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Train the model

Requires `dataset.xlsx` in the project root with `Depth` and `ln_Cost` columns.

```bash
python src/train_model.py
```

This saves `model.pkl` (model + coefficients + depth range + metrics) to the project root.

### 3. Run the app

```bash
streamlit run app.py
```

Opens at `http://localhost:8501`.

## Running with Docker

```bash
docker build -t drilling-cost-app .
docker run -p 8501:8501 drilling-cost-app
```

Opens at `http://localhost:8501`. The image only bundles `app.py` and `model.pkl` — training data and scripts are excluded via `.dockerignore`.

## Deployment

Deployed on [Render](https://render.com) (free tier) directly from this GitHub repo using the included `Dockerfile`. Streamlit's file watcher is disabled (`--server.fileWatcherType=none`) since Render's free containers have a low `inotify` limit that otherwise crashes the app on the first websocket connection.

Also deployable on [Streamlit Community Cloud](https://share.streamlit.io) without Docker — just point it at `app.py`.

## Model Details

- **Type:** Linear Regression (scikit-learn)
- **Feature:** Depth
- **Target:** ln(Cost)
- **Related analyses** (in `src/`): an OLS regression using the Bourgoyne Model (`analysis.py`), and an asymptotic learning curve model across sequential wells (`learning_curve.py`)
